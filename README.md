# Shop Bill Calculator

A simple Java program that calculates a customer's bill in a shop.

## What it does
- Asks how many items the customer is buying
- Reads the price and quantity of each item
- Adds up the total
- Gives a 10% discount if the total is UGX 50,000 or more
- Prints a receipt
- Asks if there is another customer

## Concepts used
- **Do-while loop:** serves the next customer (runs at least once)
- **While loop:** rejects a quantity that is 0 or less
- **For loop:** reads each item's price and quantity
- **Ternary operator:** decides whether the discount applies

## How to run
1. Open `ShopBill.java` in Eclipse (or any Java IDE).
2. Click **Run**.
3. Enter the details in the console.
